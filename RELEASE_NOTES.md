Your own compact, offline toolkit.

- Little Sign: sign PDFs with a touchpad, add names/dates, and save.
- PDF Kit: merge PDFs, reorder files, and extract page ranges.
- Image Clean: convert images and remove embedded metadata from new copies.
- Password Studio: cryptographically random passwords, generated locally.
- Add your own web tools and local apps to the shelf.
- Signed updates with download and restart controls.

**Windows:** Download **mytools.exe** (installer). Uses the system WebView2; installs it once if absent.

**Linux:** Download **mytools-linux-x86_64.tar.gz**, extract it, then run `./install.sh` to create desktop/app-menu shortcuts. Requires system WebKitGTK 4.1 and GTK3. RPM and DEB packages are provided for package-manager installation; use your package manager to update system-owned installations.

No accounts, ads, analytics, subscriptions, or document uploads. Release size checks keep the Windows installer and Linux portable archive below 10 MB. These releases are signed for in-app update verification; the Windows installer does not yet have a paid Authenticode certificate.
